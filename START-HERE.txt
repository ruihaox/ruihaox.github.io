RUIHAOX 个人网站 · 使用说明

这是为 https://github.com/ruihaox/ruihaox.github.io 准备的初版网站。
采用 GitHub Pages 自带的 Jekyll，日常写作可以直接在网页里完成。
所有网站文件都是公开内容；私人原稿请继续留在自己的笔记工具里。

一、上传网站

1. 解压压缩包，打开里面的 ruihaox-site 文件夹。
2. 在 GitHub 打开 ruihaox/ruihaox.github.io 仓库。
3. 点 Add file → Upload files。
4. 把 ruihaox-site 里面的文件和文件夹一起拖进去。
   重要：上传的是里面的内容，不是 ruihaox-site 这个外层文件夹。
   其中必须包括 _config.yml、_layouts、_includes、_posts、assets、index.html。
   保留这些文件名开头的下划线。
5. 检查列表里是 index.html、_config.yml、assets/... 等，
   而不是 ruihaox-site/index.html。
6. 点 Commit changes 保存。原来的 README.md 可以保留，这个包不会覆盖它。

二、开启 GitHub Pages

打开仓库 Settings → Pages。
Source 选择 Deploy from a branch。
Branch 选择 main，文件夹选择 /(root)，点 Save。
如果你的默认分支不是 main，则选择实际的默认分支。
等待几分钟，到 Pages 页面查看发布状态；首次发布可能需要约 10 分钟。
发布成功后，地址为 https://ruihaox.github.io/。
地址只有在 GitHub 发布成功后才能访问，本压缩包本身不会自动上传。

三、第一次修改

首页文字：编辑 index.html。
自我介绍：编辑 about.md。
站点名称和简介：编辑 _config.yml，保留 url 和 baseurl 配置。
所有占位文章均有“示例文章”标签；可以先试读，再替换或删除。
替换为自己的文章时，把 demo: true 这一行删除。
删除示例文章会影响列表；不会影响网站结构。

四、写一篇新文章

1. 在 GitHub 打开仓库，选择 Add file → Create new file。
2. 文件名填写 _posts/年-月-日-英文短名.md。
   例如：_posts/2026-11-07-my-first-diary.md。
   日期换成文章实际日期，年月日都补足位数。
3. 从 templates/diary-template.md 或 templates/research-template.md
   复制内容到新文件。
4. 改标题、日期、分类、标签和摘要，再写正文。
   保留开头和结尾的两行 ---，以及中间的字段名。
5. 点 Commit changes。
6. 等 GitHub 重新发布，文章会自动出现在首页和对应分类里。

日期说明：示例使用 -0800 时区偏移。
请按写作所在地设置，比如中国时区可使用 +0800。
文章日期晚于当前时间时，Jekyll 默认不会发布，注意不要无意写成未来时间。

五、从 HackMD 复制

可以把 HackMD 的 Markdown 正文复制到文章的第二个 --- 之后。
如果复制过来的第一行 # 标题与 title 字段重复，可以删除该行。
普通标题、段落、列表、链接和代码块可以直接使用。
HackMD 的专属语法（如 ::: 提示框、某些嵌入和图表）需要单独调整。

六、写数学公式

科研文章在开头字段里保留 math: true。
独立公式用两行 $$ 包起来；这与 HackMD 的常见写法一致。
本模板用 Kramdown + MathJax，行内公式建议使用 $$x_i$$。
MathJax 也配置了 $x_i$ 识别，但复杂行内公式优先用 $$...$$，
避免 Markdown 提前处理反斜线、下划线和其他符号。

例子：

设 $$p(x)$$ 是概率密度。

$$
\int_{-\infty}^{\infty}p(x)\,\mathrm{d}x = 1.
$$

MathJax 从 jsDelivr 加载；公式显示需要读者的浏览器能访问该服务。
如果页面正文正常而公式没有排版，请先确认是否存在公式脚本网络错误。

七、上传图片

建议把要公开的图片放在 assets/images/ 目录下，
正文引用例如：![图片说明](/assets/images/photo.jpg)。
只有要公开的图片才上传到仓库。

八、页面与文件

index.html：首页
diary.html：日记分类页
research.html：科研笔记分类页
about.md：关于我
_posts/：公开文章，列表自动按日期倒序排列
_layouts/、_includes/：页面结构
assets/style.css：配色、字体与手机布局
assets/site.js：标题、摘要、标签搜索
templates/：写作模板，不会发布为网站页面

搜索只匹配当前列表的标题、摘要和标签，不是全文搜索。
本网站不含登录、私密文章、评论、统计或自动同步功能。

九、检查发布失败

如果 Pages 页面显示构建失败，打开仓库 Actions 里最近一次构建。
保留报错内容，再定位文章日期、YAML 字段或文件位置的问题。
如果地址 404，先确认 Pages 已部署成功，发布分支和根目录设置正确。
