RUIHAOX · Academic website, Journal & Notes

这是参考站源码基础上的完整改版草稿，尚未上传或发布。

页面结构：
About / Research / Education / Experience / Misc / CV
Misc → Journal（中文日记） / Notes（英文科研笔记）
界面为英文；Journal 的文章标题、摘要和正文可以写中文。

一、先预览

解压整个包，打开外层的 ruihaox-academic-preview.html。
预览里的个人资料、院校、项目、经历、照片和 CV 是占位内容。
这是样式预览；正式网站仍由 GitHub Pages 构建。

二、源码和授权

本版直接复用了参考站的 CSS、外观设置和研究卡片图形代码。
Research 使用原 Selected projects 的卡片版式，研究内容不再分成两个栏目。
News 和 Community & workshops 暂不展示。
交互式 Canvas 背景和鼠标操作提示已移除。
参考站来源和复用范围记在 SOURCE-NOTICE.txt 中，并在页脚保留来源链接。
原 ZIP 没有网站整体许可证；字体自带的 OFL 只覆盖字体。
这个改稿供你本地审阅，公开沿用原站源码前请确认原作者的许可。
保留来源说明本身不等于已经获得许可。

三、上传新版

1. 在 GitHub 仓库打开 Code → main。
2. 选择 Add file → Upload files。
3. 上传本包 website 文件夹“里面”的所有文件和子文件夹。
   根目录应直接看到 index.html、misc.html、cv.html、style.css、academic.css、
   appearance.js、site.js、misc-search.js、_config.yml、_data、_includes、
   _layouts、_posts 和 assets。
4. 不要把外层 website 文件夹本身上传。
5. 不要上传外层预览文件。
6. 提交到 main，等待 Actions 最新一次 pages build and deployment 成功。

本包没有 .nojekyll。参考站里的 .nojekyll 不能一同上传，因为本版保留
Jekyll 来生成 Markdown 文章。如果你之前额外上传过 .nojekyll，需先移除它。
Mac 的 .DS_Store 没有用途，也不在本包中。
Pages 仍使用 main + /(root)，不需要改发布方式。

本次会替换首页和模板；示例文章也改成了中文 Journal、英文 Notes。
如果你已经改写了同名示例文章，上传时保留你自己的文章版本。
其他已有 _posts 文章会继续按 categories 分入 Journal 或 Notes。

四、最常用的编辑位置

_data/profile.yml：名字、侧栏介绍、首页自我介绍、研究兴趣、邮箱、GitHub、LinkedIn、照片和 CV 路径。
_data/academic.yml：Research 卡片、Education、Experience 的具体内容。
index.html：主页页面结构，一般只改数据文件即可。
misc.html：Misc 页面与 Journal / Notes 两个栏目。
_posts/：文章。

个人资料和学术内容中的“Your institution”“Research project title”“Dates”等是明确的占位内容。
它们不是从参考作者那里复制的个人经历，需要换成你自己的事实。
没有提供自己的信息之前，CV 入口会打开一个英文占位页面，不会链接到对方的 CV。

五、Email、LinkedIn、照片和 CV

Email 和 LinkedIn 已在首页与侧栏显示。
当前没有你自己的联系地址，因此先以无跳转的文字占位。
在 _data/profile.yml 中把 email 和 linkedin 两个空值改成自己的邮箱和完整 LinkedIn 链接，
它们就会自动变成可点击的链接。GitHub 链接已指向 ruihaox。

把自己的照片上传到 assets/profile.jpg，PDF 上传到 assets/cv.pdf。
在 _data/profile.yml 中填写：

portrait: /assets/profile.jpg
cv_file: /assets/cv.pdf

填写后，首页自动显示你的照片，侧栏 CV 链接指向你的 PDF。
留空时显示占位图和 CV 页面，避免出现失效链接或别人的资料。

六、写 Journal 和 Notes

在 _posts 新建 YYYY-MM-DD-english-slug.md。
Journal 使用 categories: [diary]；Notes 使用 categories: [research]。
标题和正文按你选择的语言写；本版约定 Journal 中文、Notes 英文。
从 templates/journal.md 或 templates/notes.md 复制开头字段，再写正文。
更换 date 中的日期、时间和时区，避免误设成未来文章。
在中国写作可把时间偏移改成 +0800。

例如：

---
title: "My note title"
date: 2026-11-07 12:00:00 +0800
categories: [research]
tags: [reading]
description: "A short summary."
math: true
---

正文从第二个 --- 下面开始。
数学块用 $$ 包围；行内复杂公式也建议使用 $$x_i$$，以保护 Markdown 转换中的转义字符。
MathJax 也启用了常见 $x_i$ 写法。

七、更新后已有内容去哪里了

主页 Research 使用卡片展示研究内容；科研文章在 Misc → Notes。
旧 /diary/、/research/ 和 /about/ 入口会跳转到对应新位置。
文章自己的原有 URL 仍由 _posts 的日期、分类和文件名生成。
私人日记仍留在自己的笔记工具里；上传到这个公开仓库的文件都是公开内容。
